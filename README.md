# SyntaxHRM Final Project - Group 2 - Batch 27

This repository contains the automation framework for the SyntaxHRM Final Project.

## Tech Stack

- Java
- Selenium WebDriver
- Cucumber
- JUnit
- Maven
- Page Object Model

## Framework Structure

- `pages` - Page Object classes
- `utils` - Utility classes
- `steps` - Cucumber Step Definitions
- `runner` - Cucumber Runner class
- `features` - Cucumber feature files
- `config` - Configuration properties

## Current Framework

The baseline framework includes:

- Maven dependencies
- ConfigReader
- DriverManager
- CommonMethods
- LoginPage
- DashboardPage
- Login feature
- Login step definitions
- Cucumber runner
- Hooks for browser cleanup
